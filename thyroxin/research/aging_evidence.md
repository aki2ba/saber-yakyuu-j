## 2. 低下の「形」は線形でなく**加速的**（複数の独立手法が一致）

| 軸 | 実測 | 出典・確度 |
|---|---|---|
| **Sprint Speed** | **年 -0.16 ft/s**（線形回帰・約5,000選手シーズン）。27歳以下は78.5%がリーグ平均超 → 28-32歳47.5% → **33歳以上15.2%** | MLB.com公式Statcast記事 — **高** ／ 線形回帰は個人ブログ — 中 |
| **守備(DRS)** | 25歳ピーク → 30歳まで **年-0.4ラン** → 34歳まで **年-0.75ラン**（**後半で約2倍に加速**） | Sports Info Solutions — 中 |
| **捕手フレーミング** | 25歳ピーク → **26-30歳はほぼ横ばい** → 31歳以降に緩やかな低下。**ピークと最低期の差はわずか2ラン以内** | THT/Substack — 中 |
| **球速** | **28歳まではピーク比0.5mph以内を維持** → **29歳から約-1mph** → **32-33歳で二段階目の加速**。生涯総低下 21→38歳で **-3.7〜-4.0mph** | FanGraphs (Zimmerman) — 中 |
| 打者 Hard Hit% | 20-25上昇 → **26-35横ばい** → **35歳以降で急減** | FanGraphs — 中 |
| 捕手の打撃低下 | 全ポジションより**早く落ちるが、崖ではなくカーブ** | FanGraphs — 中 |

> **★示唆**: 現行の `declineAccel: 0.12`（毎年12%ずつ衰え幅が増える指数モデル）より、
> **「ある年齢まで横ばい → その後折れ曲がる区分関数」**のほうが実測に近い可能性が高い
> （特に球速: 28歳まで平坦 → 29歳で折れる → 32-33歳でさらに折れる）。

**「35歳の崖は実在か統計的アーティファクトか」は学術的に決着していない**
（Lichtman: 生存者バイアスで過大評価 ⇔ Judge: むしろ過小評価。Nguyen 2022 の多重代入は「真の低下はもっと急」）。

## 3. 若手の成長・bust

- **年次成長幅の標準偏差（我々の growthVarYoung=0.35 に対応する実測値）は未確認**（定性的傾向のみ）
- bust率は FV等級別に 14%（60FV）〜53%（45FV投手）— `scouting_market_evidence.md` 参照
- **高卒 vs 大卒**:
  - 査読論文（McCue 2019, Frontiers in Psychology, n=2,291・**確度高**）: 高卒はデビューが有意に若い
    （p<.001）が、**生涯WARに経路間の有意差なし**
  - NPBドラフト1位 n=108（2013-2021）: 高卒 平均WAR **1.46** / 大卒 **2.37** / 大卒社会人 **2.46**。
    ただし同期間のMVP 4人中3人が高卒 ＝ **平均は低いが上振れの絶対値は高卒が大きい（分布形状の違い）** — 確度中
- **晩成型の頻度は未確認**。むしろ PED規制(2006)以降「遅咲きで急成長するパターン自体が構造的に減少」
  （Zimmerman/SABR — 中）

## 4. 「覚醒」は実在するか

- 打率の年次相関 R²<15% ⇔ **三振率の年次相関 R²≈70%** → 「当たり」の変動の大半は運、
  **選手のコントロール下にある指標（K%/BB%/打球の質）では真の能力シフトが示唆される**
- Changepoint検出（Glazer, arXiv:2510.25961, 2025）: MLB指標に**統計的に有意な非連続変化を検出できる**
  （シミュレーションのground-truthで91%検出）。**「覚醒」は完全な幻想ではない**
- **年次発生率（我々の breakout 確率に対応する実測値）は未確認**
- イップス/制球崩壊の**プロでの年間発生率も未確認**（日本の大学野球選手の自己申告45.8%はサンプルも対象も別物）
