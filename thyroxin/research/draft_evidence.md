## 3. ★★分布は極端に右へ歪んでいる

- 全指名者の **85.9%がMLB出場なし**、**97%が生涯WAR5未満**
- **1巡目でも bust**: 年率WAR1.5未満が **60%（1-5位）〜85%（16-20位）**（FanGraphs Community・
  2000-2010・各群n=55・確度高）。メジャー未到達も1巡目で **33.3%**
- **下位からスターが出る**: Mike Piazza（62巡目・全体1,390位）、Albert Pujols（13巡目・全体402位）。
  直近オールスター173人中 **11巡目以降が19人(11%)**、1巡目は52人(30.1%)（確度中）
- 「中央値 << 平均」＝ **少数の大当たりが平均を作る**。FanGraphs は「11巡目以降は歪みが大きいので
  中央値を使う」と明記

## 5. NPBドラフト

**制度**（NPB公式・確度高）: 1位は全球団同時提出→重複は**抽選**→外れ1位は再指名。2位以降はウェーバー
（前年最下位から）、3位はその逆順、4位以降は交互。支配下は各球団**原則10名まで**（全体120名到達で終了）。
育成ドラフトは2005年導入・希望球団のみ。2024年実績: 育成54名（最多ソフトバンク13名）。

**指名順位別**（1.02 / 大南淳 2025-05・2013-2023の1巡目132名・確度高）:
1巡目の通算WAR合計 574.8。**2巡目193.6 を 3巡目232.0 が上回る逆転現象**（非単調）。

**★育成選手の成功率**

| 指標 | 値 | 出典・確度 |
|---|---|---|
| 一軍出場率 | **26.9%**（78/288・制度開始〜2018） | Number Web 2019・高 |
| 支配下登録率 | **約34%**（143/421・〜2021） | THE DIGEST 2022・高 |
| 高卒育成の支配下昇格率 | 27%（**球団差が大きい**: 阪神・ヤクルトは半数超、一部球団は2割以下） | note 2024・中 |

## ★現行実装との乖離（実測込み）

**実測（14年・シム）**: ドラフト新人 **4.8人/球団年**、一軍で1打席でも出場 **70%**、
レギュラー級(400PA/400BF) **19%**、主力級 **5%**

| # | 乖離 | 重大度 |
|---|---|---|
| D1 | **ドラフトが「引退で空いた枠を埋めるだけ」**（4.8人/球団年）。現実は**10人指名して大半が芽の出ないまま消える**（NPB支配下10＋育成4.5）。＝「大量に獲って淘汰する」という構造そのものが無い | **S** |
| D2 | **指名順位ごとの価値曲線が無い**。プール枯渇による間接的な減衰のみで、`generateRookie` は順位に関わらず同一の真値分布から生成される | **S** |
| D3 | **真値分布の右の歪みが無い**（正規分布）。現実は「97%がWAR5未満・少数の大当たりが平均を作る」極端な右歪み | **S** |
| D4 | **経路別（高卒/大卒/社会人）のリスク差が無い**。`pickCohortAge` は年齢だけを変える。現実は**高卒投手のデビュー率が大卒より16.8pt低い**（野手では4.3ptと小さい） | A |
| D5 | **投手/野手のリスク差が無い**（TINSTAAPP）。WAB/年は大卒野手0.76 ⇔ 高卒投手0.35 と2倍以上 | A |
| D6 | 育成の成功率が較正されていない（NPB実測: 一軍出場率26.9%・支配下登録率34%） | A |
| D7 | 難ポジ（捕手/遊撃）の指名プレミアムが無い（`wDef` で間接的にのみ） | B |
