# 実装 vs 現実の徹底検証 — MLB物理プロキシ＋NPB公式シーズン集計（2026-07-12）

ユーザー指示「徹底的に検証してほしい。『MLB物理を代理参照＋NPB公式のシーズン集計』で」への回答。
検証は再実行可能な形で `tools/realism-check.mjs`（`npm run realism`）に恒久化した。
参照値はすべて `tools/realism-refs.mjs` に出典URL・シーズン付きで収載。

## 方法

- **打球物理（この打球ならどうなるか＝条件付き分布）**: NPBに一球粒度の公開データは存在しない
  ため、MLB Statcast / FanGraphs の公開実測値を代理参照とした。**Statcastの打球分類はLA閾値
  （GB<10° / LD 10-25° / FB 25-50° / PU>50°）でシムの `battedType` と同一定義**であることを
  確認済み＝定義変換なしでそのまま比較できる。シム側は30万打球（打者/投手を実生成リーグから
  一様サンプル・中立球場）で測定。
- **シーズン総量**: npb.jp公式の年度別チーム成績（2023/2024/2025・打撃tmb_c/p・守備tmf_c/p、
  全ページ取得成功・原データ保存済み）から12球団の平均/最小/最大を計算し、シムの2シード平均と比較。
- **判定**: 現実と整合＝GATE（帯つき・破ったら`npm run realism`がFAIL）。乖離＝WATCH（既知の
  穴/新発見として明記・修正後に帯つきGATEへ昇格させる運用）。

### ⚠️ 乖離（WATCH 12件・すべて公式/公開実測との突き合わせで確定）

**【構図】打球の入力分布は正しいのに、「強い打球・深い打球の結果への写像」が系統的に歪んでいる。**
以下の1〜4は独立の穴ではなく、打球結果解決層（外野の深い打球とフェンス際）の同根の歪み:

1. **HRが間違ったLA帯から出ている（新発見・最重要）**
   sim: HR平均LA 25.5°・**HRの46%がLD帯（LA<25°）**・HR/FB 4.2%
   現実: HR平均LA ~28°・LD帯HRは少数派・HR/FB 18.1%（MLB2023）/ NPB概算8-10%
   → 総HR数は較正で合っているが、**「どんな打球がHRになるか」が現実と違う**。バレル帯
   （高LA・高EV）のフライがHRにならず、代わりに低いライナーがフェンスを越えている。
   audit既知の「LA<15°はHR判定外」「フェンス越え落下の非HR帯」と同じHR判定式の問題系。

2. **バレルがほぼ自動安打**: sim BA .886 / SLG 3.27 vs 現実 .742-.822 / 2.39-2.59
   → 現実では約2割のバレルがフェンス際で捕られる。simは深いフライの捕球攻防が乏しい。

3. **フライが安打になりすぎ**: FB BABIP sim .201 vs 現実 .127
   → 二塁打過多（下記6）と同根。深いフライの「落ちるか捕られるか」の境界が甘い。

4. **強い打球（特にゴロ）の安打が少なすぎ**: GB BABIP sim .209 vs 現実 .232-.239、
   Hard-Hit打率 sim .414 vs 現実 .506-.524
   → audit既知の「EV分布に弱接触の左裾がない→内野安打が湧かない」と同根。強いゴロが
   内野を抜ける率も低い。

5. **盗塁が過剰（新発見）**: sim 116.8個/球団・成功率.749 vs NPB実測 66-77個・.672-.707
   → 企図数が約1.6倍。走者能力→企図ゲートの再較正が必要（calibrateの盗塁王帯[30,65]は
   通るがリーグ総量が見えていなかった）。

6. **二塁打過多**: 2B/H sim .206 vs NPB実測 .165-.173（3年安定）
   → simはMLB水準（.202）になっている。NPBへ寄せるには2B→1Bミックスの組み替えが必要。

7. **犠飛不足**: sim 20.5/球団 vs NPB実測 31.1（3年とも31前後で極めて安定・帯20-47）
   → R1の深さ依存化（tagMinDistM/sfBase）が保守的すぎた。

8. **犠打不足**: sim 70.1/球団 vs NPB実測 平均93-111（12球団の最少でも57）
   → 特にDH有リーグ(sim 33)が現実（パ球団も85+の年が普通）から乖離。**既存calibrateの
   shPerTeamDh帯[30,75]自体が公式実測とズレていた**ことも今回判明。

9. **ポップ被打率**: sim .045 vs 現実 .020（audit既知: 捕手・投手が守備網に不在）

### 🎯 時代整合（最大の設計判断・要ユーザー決定）

sim得点環境: AVG .256 / R/G 4.11 / HR 120（**NPB 2015-19「飛ぶボール」時代**への較正・config注記で自覚済み）
NPB 2023-25実測: AVG .242-.244 / **R/G 3.29-3.48** / HR 81-104（低反発時代）

三原則②は「**現状の**セパ両リーグ近似」。現行NPBに寄せるなら得点環境一式の再ベースライン
（AVG/HR/R・それに依存する全較正帯の張り替え）が必要で、これは独立の大型較正プロジェクト。
どちらの時代をゲームの「現実」とするかはユーザー判断事項。

## 修正の推奨順序（検証結果からの提案）

1. **打球結果解決層の再設計（上記1-4を一体で）**: HR判定をフェンス越え物理に一本化（hrScaleの
   掛け方修正・LA<15°制限撤廃）＋フェンス際の捕球攻防＋EV左裾（弱接触）導入＋FB/GBの安打境界
   再較正。これで「HRのLA分布・バレル結果・FB/GB BABIP・Hard-Hit打率・2B/H」が連動して現実に寄る
2. **盗塁企図の再較正**（steal.attemptBase/採配ゲート）: 総量66-77/球団・成功率.67-.71へ
3. **犠飛/犠打の再較正**（sfBase・buntAttempt系）: SF≈31・SH≈95-110へ（calibrate帯も公式値へ張り替え）
4. **時代ベースラインの決定**（ユーザー判断）→ 選択に応じて得点環境を再較正

## 再現方法

```bash
npm run realism   # GATE/WATCH全項目＋出典付き参照値
```
参照値の生データ: NPB=エージェント収集の final.json（tmb/tmf各ページのHTML保存済み・
セッションscratchpad）、MLB=realism-refs.mjs内の出典URL群。
